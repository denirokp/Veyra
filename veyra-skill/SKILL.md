# Veyra — сверка со стратегическим корпусом

> Статус: Фаза 1/2. Работает через MCP-сервер `veyra` (каталог
> `veyra-mcp/`). Образец упаковки — скилл `quality-metrics`.

## Предусловие

Скилл работает только при подключённом MCP-сервере `veyra`. Если его
инструменты недоступны — скажи пользователю, что нужно подключить
MCP-сервер veyra, и **не выдумывай находки**.

## Инструменты veyra (MCP)

| Инструмент | Когда вызывать |
|---|---|
| `search_corpus(query)` | «что мы уже знаем про X» — перед написанием нового |
| `check_initiative(text)` | сверка инициативы с корпусом → расхождения |
| `find_contradictions()` | известные числовые/логические нестыковки |
| `find_open_promises()` | что обещали и не сделали |
| `find_gaps()` | серые зоны — без ресурсов/владельцев |
| `get_document(id)` | полный документ для проверки цитаты |
| `corpus_stats()` | сводка по корпусу |

## Когда вызывать скилл

«Проверь инициативу», «нет ли противоречий с прошлыми решениями»,
«что мы обещали по теме X», «где у нас серые зоны», «что мы уже знаем
про Y». Не вызывать для простого поиска по Confluence — у Veyra своя
ниша: логика противоречий, не релевантность.

## Режим 1 — Диалог

Пользователь спрашивает → вызови подходящий инструмент veyra →
перескажи находки. **Каждое расхождение — с цитатой и ссылкой на
документ-источник.** Если veyra не вернула находку — скажи это прямо,
не доисдумывай. Учитывай поле охвата в ответе: «расхождений нет» имеет
смысл только в пределах проверенного объёма.

## Режим 2 — Отчёт в Confluence

По результату `check_initiative` собери страницу. `scripts/report.py`
форматирует ответ инструмента в Confluence-разметку (заголовок +
таблица расхождений + источники) — как у `quality-metrics`.

## Чего скилл НЕ делает

- Не выдумывает находки без цитаты из источника.
- Не пишет документ за пользователя — финальный текст пишет человек.
- Не выдаёт «расхождений нет» без указания охвата проверки.
