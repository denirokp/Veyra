# Veyra — инструкция пользователя

> Черновик (Фаза 1, Трек F). Полная инструкция — после пилота (Фаза 3).

## Что это

Veyra сверяет инициативу или документ со стратегическим корпусом
коммерческого блока и показывает расхождения, противоречия и
невыполненные обещания — каждое с цитатой и ссылкой на источник.

## Установка

После публикации скилла (Фаза 3):

```bash
avito ai skills install veyra
```

## Использование

**Диалог** — спроси у ассистента:

> «Проверь инициативу: <текст>»

**Отчёт в Confluence** — попроси собрать страницу:

> «Сделай отчёт по расхождениям для инициативы X»

Скилл построит 3-колоночную таблицу: расхождение / источник / рекомендация.

## Настройка

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `VEYRA_MCP_URL` | адрес MCP-сервера veyra-mcp | `http://localhost:8000` |
| `VEYRA_MCP_DEV_TOKEN` | токен dev-режима (опционально) | пусто |

## Ограничения

- Veyra не пишет документы за тебя — она находит расхождения, решение за человеком.
- Находка без цитаты не показывается — если источник не найден, расхождение отбрасывается.
- Это не замена поиску по Confluence — ниша Veyra в логике противоречий.
