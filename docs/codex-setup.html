AI Lab в Codex

Настройка с нуля на компьютере, где стоит только приложение Codex. 3 шага, ~2 минуты.

Ставить и качать почти ничего не надо: сервер AI Lab уже работает в облаке. Нужно только один раз вписать в Codex ссылку на него. Скилла/zip тут нет — это только у Claude.
Что нужно заранее: приложение Codex установлено и ты в него вошёл (если у коллеги Codex уже отвечает в чате — всё готово, идём дальше).
1

Подключить AI Lab обязательно

  1. В Codex открой: значок ⚙️ шестерёнки → MCP settings → Open config.toml. Откроется текстовый файл настроек.
  2. Вставь в самый конец файла эти две строки и сохрани (Ctrl+S / ⌘S):
[mcp_servers.ai-lab]
url = "https://veyra.fly.dev/mcp"
Это обычный текстовый файл — сломать этим ничего нельзя. Сервер открытый: пароль/токен не нужен, больше ничего не заполняем.
2

Добавить правила по желанию

Файл AGENTS.md (пришлёт Денис) учит Codex отвечать правильно: всегда давать источник, не выдумывать, показывать охват.

  1. Сохрани файл AGENTS.md в ту же папку, где только что открылся config.toml из шага 1 (то есть как ~/.codex/AGENTS.md).
  2. Имя файла — ровно AGENTS.md, ничего не переименовывать.
Можно пропустить — AI Lab заработает и без этого шага, просто ответы будут «сырее».
3

Перезапустить и проверить

  1. Полностью перезапусти Codex (чтобы он увидел новый сервер).
  2. В чате напиши обычными словами:
вызови ai-lab corpus_stats

Ответит: 128 документов и дата обновления — значит всё работает. 🎉

Дальше спрашивай как коллегу-аналитика:

Проверь инициативу: <краткое описание>
Какие обещания по <теме> не закрыты?
Нет ли противоречий по <метрике> между документами?
Что мы уже знаем про <тема>? Дай с источниками

Если не сработало

Codex «не видит» ai-labПроверь, что две строки из шага 1 сохранились (⚙️ → MCP settings → Open config.toml), и перезапусти Codex. Список подключённого — команда /mcp в чате.
Ошибка про url / «not supported»Обнови приложение Codex до свежей версии — подключение сервера по ссылке (URL) появилось недавно.
corpus_stats молчитЕсли сам Codex у коллеги отвечает в чате — сеть в порядке, ai-lab это просто ещё один адрес. Подожди минуту и повтори.
Отвечает «не по правилам»Проверь, что AGENTS.md из шага 2 лежит рядом с config.toml (как ~/.codex/AGENTS.md).
