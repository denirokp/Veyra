AI Lab — подключение

Помощник внутри Claude / Codex: находит в стратегических документах противоречия, незакрытые обещания и пробелы — с цитатой и ссылкой на источник.

Нужно: платная подписка Claude (Pro / Team / Max) и включённый западный VPN. Если Claude.ai у вас открывается — VPN уже ок. Настройка ~5 минут, один раз.
1

Подключить данные (коннектор)

Settings ⚙️ → Connectors → Add custom connector. В поле URL вставьте (поля OAuth оставьте пустыми) → Add:

https://veyra.fly.dev/mcp
2

Загрузить скилл

Settings → Skills → Upload skill → выберите файл ai-lab-skill.zip (пришлёт Денис).

Скилл — это правила, по которым Claude пользуется данными: всегда даёт источник, не выдумывает, показывает охват. Без него хуже — загрузите.
3

Спросить

В новом чате убедитесь, что коннектор ai-lab включён (значок инструментов у поля ввода), и пишите обычными словами:

Что мы уже знаем про <тема>?
Проверь инициативу: <текст>
Какие обещания по <теме> не закрыты?
Нет ли противоречий по <метрике> между документами?

Если что-то не так

Claude пишет «инструментов нет»В чате включите коннектор ai-lab (галочка в панели инструментов у поля ввода).
Claude.ai не открываетсяВключите западный VPN.
Нет «Add custom connector» / «Skills»Нужна платная подписка Claude.
Спрашивай обычными словами. AI Lab найдёт в корпусе факты, противоречия, незакрытые обещания и пробелы — каждое с цитатой и ссылкой на документ.

✍️ Ревью и со-написание документа

Приложи черновик — разберёт по структуре, сверит фактуру с корпусом, допишет в стиле (числа не выдумывает — ставит [TODO]).

Вот черновик: <вставить>. Проверь на противоречия с корпусом и допиши слабые места

Что ждать в ответе

  • Каждый факт — со ссылкой на документ-источник.
  • Отделяет ФАКТ (есть в документах) от ГИПОТЕЗЫ (вывод).
  • Показывает охват: «проверено N из M по теме, данные на дату».
  • Данных мало — честно скажет, не выдумает.
  • Документ целиком за тебя не пишет — черновик с [TODO], финал за человеком.

Чтобы спрашивать лучше

  • Будь конкретен: назови тему, метрику, инициативу, период.
  • Нужна таблица/отчёт — так и скажи («сделай таблицу расхождений»).
  • В конце ответа он предложит 2–3 follow-up вопроса — жми на них.
  • Ответил «мало материала» — переформулируй: синонимы, RU↔EN, полное название вместо сокращения.
Границы: знает только наш корпус (загруженные документы), не живые системы и не весь интернет. Корпус — снимок на дату; самые свежие правки могут ещё не попасть. Не заменяет чтение первоисточника — показывает, куда смотреть.
Это для тех, у кого установлено приложение Codex (отдельная программа OpenAI). Пользуешься только Claude.ai? Тебе нужна вкладка «Claude.ai — подключение», а не эта.
Как и в Claude.ai, два шага: подключить данные (сервер ai-lab) и дать правила (файл AGENTS.md — у Codex нет «скиллов», как у Claude). Всё делается в самом приложении, терминал не нужен.
1

Подключить данные (сервер ai-lab)

  1. Открой приложение Codex.
  2. Настройки: значок шестерёнки ⚙️ → MCP settings → Open config.toml. Откроется текстовый файл настроек.
  3. Допиши в конец файла эти две строки и сохрани:
[mcp_servers.ai-lab]
url = "https://veyra.fly.dev/mcp"
Это подключает данные AI Lab. Сервер открытый — пароль/токен не нужен, больше ничего не заполняем.
2

Дать правила (файл AGENTS.md)

Этот файл говорит Codex, как пользоваться данными: всегда давать источник, не выдумывать, показывать охват. Возьми ai-lab/AGENTS.md (пришлёт Денис) и положи его в папку проекта, который открываешь в Codex — правила подхватятся из этой папки.

Хочешь, чтобы правила работали в любом проекте — положи тот же файл как ~/.codex/AGENTS.md (та же папка настроек Codex, где и config.toml из шага 1).
3

Проверить

Перезапусти Codex (чтобы он увидел новый сервер) и в чате напиши обычными словами:

вызови ai-lab corpus_stats

Ответит числом документов (128) и датой обновления — значит подключилось. Дальше спрашивай как на вкладке «Как пользоваться».

Если что-то не так

Codex «не видит» ai-labПроверь, что строки из шага 1 сохранились (⚙️ → MCP settings → Open config.toml), и перезапусти Codex. Список подключённого — команда /mcp в чате.
Ошибка про url / «not supported»Обнови приложение Codex до свежей версии — подключение сервера по ссылке (URL) появилось недавно.
Отвечает «не по правилам»Проверь, что AGENTS.md из шага 2 лежит в папке открытого проекта (или как ~/.codex/AGENTS.md).
Для Claude Code всё уже в репозитории Veyra: ai-lab/.mcp.json (сервер) и ai-lab/skills/SKILL.md (правила).
