AI Lab — подключение

Помощник внутри Claude / Codex: находит в стратегических документах противоречия, незакрытые обещания и пробелы — с цитатой и ссылкой на источник.

Нужно: платная подписка Claude (Pro / Team / Max) и включённый западный VPN. Если Claude.ai у вас открывается — VPN уже ок. Настройка ~5 минут, один раз.
1

Подключить данные (коннектор)

Settings ⚙️ → Connectors → Add custom connector. В поле URL вставьте (поля OAuth оставьте пустыми) → Add:

https://veyra.fly.dev/mcp
2

Загрузить скилл

Settings → Skills → Upload skill → выберите файл ai-lab-skill.zip (пришлёт Денис).

Скилл — это правила, по которым Claude пользуется данными: всегда даёт источник, не выдумывает, показывает охват. Без него хуже — загрузите.
3

Спросить

В новом чате убедитесь, что коннектор ai-lab включён (значок инструментов у поля ввода), и пишите обычными словами:

Что мы уже знаем про <тема>?
Проверь инициативу: <текст>
Какие обещания по <теме> не закрыты?
Нет ли противоречий по <метрике> между документами?

Если что-то не так

Claude пишет «инструментов нет»В чате включите коннектор ai-lab (галочка в панели инструментов у поля ввода).
Claude.ai не открываетсяВключите западный VPN.
Нет «Add custom connector» / «Skills»Нужна платная подписка Claude.
Нужно: установленный и залогиненный Codex CLI (codex --version), локальный репозиторий Veyra (для AGENTS.md). Если api.openai.com недоступен — VPN.
1

Инструменты — MCP-сервер

Добавить сервер в ~/.codex/config.toml:

mkdir -p ~/.codex
printf '\n[mcp_servers.ai-lab]\nurl = "https://veyra.fly.dev/mcp"\n' >> ~/.codex/config.toml
Сервер открытый — токен не нужен. Codex нативно поддерживает remote HTTP MCP по URL.
2

Правила — AGENTS.md

У Codex нет «skills», поэтому правила идут через AGENTS.md (глобально):

cp ~/Code/Veyra/ai-lab/AGENTS.md ~/.codex/AGENTS.md
Правила условные («когда просят проверить инициативу / расхождения…») — обычному кодингу не мешают. Хочешь изоляцию — положи AGENTS.md в отдельную папку и работай из неё.
3

Проверить

codex
# в сессии:
вызови ai-lab corpus_stats

Ожидаемо: число документов (128) и last_indexed_at.

Если что-то не так

Codex не видит инструментыПроверь синтаксис ~/.codex/config.toml, перезапусти codex. Список серверов — командой /mcp в сессии.
Ошибка про urlОбнови Codex CLI — remote HTTP MCP по URL это свежая возможность.
401 / 403Сервер открытый, токен не нужен. Если включён MCP_AUTH_TOKEN — добавь bearer_token_env_var.
Для Claude Code всё уже в репозитории Veyra: ai-lab/.mcp.json (сервер) и ai-lab/skills/SKILL.md (правила).
1

Сервер

Уже описан в ai-lab/.mcp.json:

{ "ai-lab": { "type": "http", "url": "https://veyra.fly.dev/mcp" } }

Claude Code подхватит его из проекта (или добавь через claude mcp add).

2

Правила + проверка

Скилл — ai-lab/skills/SKILL.md (подхватывается автоматически). Проверка в сессии:

вызови ai-lab corpus_stats
