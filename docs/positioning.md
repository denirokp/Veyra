# Хроника — позиционирование

> Внутренний продукт для коммерческого блока Avito (CCO Алексей Ли).
> Veyra — кодовое имя движка. Этот документ отвечает на один вопрос:
> почему Хроника — не «ещё один агент по докам», и в чём её защищаемое преимущество.

## В одну строку

Хроника — система институциональной памяти над корпусом стратегических
документов команды: находит противоречия, ведёт реестр обещаний, выявляет
серые зоны и сбивает новые инициативы с накопленным контекстом.
**Это не агент. Это система записи.**

## Задача (из постановки Алексея)

Корпус документов команды — «бульон», из которого варится любая стратегия.
Хроника над этим бульоном:

- ловит расхождения — числовые (конфликт метрик) и **логические**
  («здесь говорите одно, здесь другое»);
- сверяет обещанное с сделанным, ловит «провалили между стульев»;
- подсвечивает возможности и метрики, которые команда не видит;
- сбивает новые инициативы — свои и из других направлений — с бульоном.

## Категориальная ловушка

В 2026 «AI-агент по корпоративным докам» — коммодити. Внутри Avito сотни
людей умеют за вечер собрать Claude + MCP + скиллы. Если Хронику
воспринимают как агентную обвязку — она проигрывает: обвязка собирается
быстрее, а Хроника тяжелее.

**Выигрыш — в смене категории, а не в «у меня агент лучше».**

## Почему Хроника — другая категория

Пять вещей, которые сессия-агент не умеет структурно:

1. **Память.** Агент в сессии стартует с нуля. Хроника — БД находок:
   противоречия, обещания, сигналы накапливаются, имеют жизненный цикл
   (`open → reviewed → resolved`).
2. **Кросс-документность на масштабе.** Противоречие между доками без общих
   слов — это эмбеддинги + сравнение по всему корпусу. Агент видит только
   то, что затащил в контекст.
3. **Проактивность.** Новый док → Хроника сама прогнала анализ при
   индексации. Агент работает только по запросу.
4. **Доверие.** Каждое утверждение трассируется к источнику; FACT/HYPOTHESIS;
   грунтинг против галлюцинаций; eval-харнесс. Агент даёт разный ответ
   каждый прогон.
5. **Общая поверхность.** Команда и руководство смотрят в одну доску.
   У агента выход — приватный транскрипт.

## Ров компаундится

Чужой свежий агент стартует с пустым бульоном. Хроника с каждой неделей:
корпус богаче, находки накапливаются, иерархия выверена, доверие растёт.
Догнать нельзя «умнее» — только переварив те же месяцы бульона.

**Ров — не алгоритм (он воспроизводим), а накопленный актив:** выверенный
корпус, БД находок, доменная логика «что считается противоречием на языке
этой команды», eval-данные.

## Table stakes vs ров

| Table stakes — есть у всех, не позиционируемся | Ров — сюда инвестируем |
|---|---|
| Загрузка доков, RAG-поиск, чат по корпусу | Стоячая детекция противоречий по всему корпусу |
| Агент-оркестрация, MCP-интеграции | Трекинг «обещано vs сделано» |
| Коннекторы к источникам | Детекция серых зон, ревью инициатив |
| | Доменная логика + feedback loop + eval |

## Рынок (проверено, 2026)

- **Glean, Onyx, Dropbox Dash, Notion AI** — поиск + чат + агенты по докам.
  Кросс-документную детекцию противоречий не делает никто из них.
- **Hebbia** — ближайший по механизму (кросс-документный анализ), но
  вертикаль finance/legal и по запросу, не постоянный мониторинг.
- **Legal CLM (Sirion, Luminance)** — ближайший аналог: сканирование
  конфликтов + трекинг обязательств, но только по контрактам.
- **Противоречия + обещания + серые зоны по стратегическому корпусу — не
  делает никто.** Подтверждённое белое пятно; академически (arXiv 2025–26)
  задача признана нерешённой.

## Ответ скептику «я на агентах сделал быстрее»

> Ты сделал ответ на один вопрос за вечер. Хроника — институциональная
> память по всему корпусу, которой пользуется команда и руководство, не
> пересобирая контекст каждый раз. Скорость сборки прототипа и продукт —
> разные категории. Прототип нельзя накопить; бульон — можно, и он уже варится.

## Что из этого следует для разработки

- Не позиционировать продукт на RAG / чате / агентах — это плумбинг.
- Основное усилие — в ров: качество детекции (claim-graph пайплайн),
  доменная логика, eval-данные, жизненный цикл находок, проактивность.
- Агент-loop и MCP — делаем на уровне «не выглядеть устаревшим», без
  переинвестиций.
- Легибельность (доски, понятные руководству за 10 секунд) — часть рва,
  а не отдельная задача.
