**Дата:** 2026-05-17
**Корпус:** 3 документа — D1 «Progress plan CY25», D2 «Sellers' education strategy 2025», D3 «B2C Journey — Deep Dive».
**Условия:** полные тексты всех 3 документов (147 729 симв.) поданы в контекст LLM; векторный индекс 111 чанков.

**Ground truth:** `scripts/gate_ground_truth.json`.

## ВАЖНО — что именно проверено (границы гейта)

Этот гейт проверил **один режим**: «полные тексты документов целиком поданы
Claude». На 3 документах это рабочий режим. На 300+ документах он
невозможен — текст не влезает в контекст; там работает retrieval, который
этим гейтом **не проверялся**.

**Следствие: гейт Фазы 1 НЕ закрывает Фазу 2.** До индексации полного
корпуса обязателен отдельный retrieval-гейт (ТЗ Фаза 1.5).

**Нашёл не «кастомный детектор», а Claude.** Index-time детекторы
`find_contradictions` (группировка метрик) и `find_logic_signals` при
индексации выдали **0 расхождений и 0 логических сигналов**. Все находки
ниже сделаны Claude при рассуждении над полным текстом, а не кастомным
кодом детекторов.

> **Примечание (post-gate).** После этого прогона index-time детекторы
> были переработаны (brief-based анализ) и теперь дают ненулевой выход
> (по `STATUS.md` — 21 расхождение / 19 логических сигналов / 215
> обещаний). Это изменение **сделано после гейта и гейтом не
> валидировано** — recall/precision переработанных детекторов
> неизвестны. Цифры этого отчёта относятся к состоянию на дату прогона.

## Ограничения достоверности (честно)

1. **Один прогон — анекдот, не измерение.** Для метрики нужен усреднённый
   результат ≥3 прогонов. N-02 в ранних попытках терялся, в этом нашёлся.
2. **Циклический ground truth.** `scripts/gate_ground_truth.json` размечен
   Claude по тем же 3 документам. Детектор — тоже Claude. Гейт меряет
   **самосогласованность модели**, не правильность. Нужна независимая
   человеческая разметка.
3. **Drop-rate не измерен как метрика.** Высокий drop-rate grounding-фильтра
   может означать не precision, а сломанную атрибуцию — нужна отдельная
   метрика «сколько фактов отброшено и почему».
4. **q5 не закрыт** — HTTP 429: личный ключ ограничен 30K вход. токенов/мин,
   запрос с полным корпусом (~45K токенов) превышает лимит. Закрывается на
   Avito gateway или повторным прогоном `run_gate.py q5_L02`.

## Вывод

Показано (в границах одного прогона): **Claude, рассуждая над полными
текстами малого корпуса, находит размеченные расхождения — с цитатами,
без видимых галлюцинаций** (4/5; q5 — rate-limit). Это анекдотический
результат для малого корпуса в full-text режиме; для метрики нужен
усреднённый результат ≥3 прогонов с измеренным precision (см.
«Ограничения», п. 1).

Это **не валидирует**: retrieval-режим, масштаб 300+ документов, index-time
кастомные детекторы (выдали 0). Гейт Фазы 1 пройден в своих границах;
Фаза 2 разблокируется только после retrieval-гейта (Фаза 1.5).
