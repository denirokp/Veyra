# AI Lab — подключение для коллег

**5 минут, без участия Дениса, работает 24/7.** Сервер живёт на Fly.io,
коллегам нужно только добавить connector в Claude.ai с токеном.

---

## Что вам понадобится

1. **Claude.ai** (web или desktop), любая платная подписка (Pro / Team / Max
   — Custom Connectors доступны на всех платных тарифах).
2. **URL и токен от Дениса** (придёт в личку):
   - URL: `https://veyra.fly.dev/mcp`
   - Authorization: `Bearer <ваш_токен>`
3. **VPN с западным exit-нодом** (для api.anthropic.com). Если Claude.ai у
   вас уже открывается — VPN настроен.

---

## Подключение (один раз)

1. В Claude.ai откройте **Settings → Connectors → Add custom connector**.
2. Заполните:

   | Поле | Значение |
   |---|---|
   | **Name** | `ai-lab` |
   | **Remote MCP server URL** | `https://veyra.fly.dev/mcp` |
   | **Authorization header** | `Bearer <токен от Дениса>` |

3. **Add connector**.
4. Готово — connector доступен во всех новых чатах.

---

## Первый запрос — проверка связи

В новом чате задайте:

```
Вызови инструмент ai-lab corpus_stats
```

Ожидаемый ответ — сводка по корпусу:

```
83 документа · 28 числовых расхождений · 2080 логических сигналов · 1055 открытых обещаний
```

Если видите цифры — всё работает. Если `unauthorized` — проверьте токен.

## Применить skill (SKILL.md) — даёт качество ответов

Connector даёт Claude **инструменты**, а skill — **правила** как ими
пользоваться (русский язык, бизнес-тон, формат таблиц, охват, follow-up'ы).
Без skill ответы будут «сырыми».

### Вариант A — Project с инструкциями (быстро)

1. **Projects → Create project** → название `AI Lab`.
2. **Custom instructions / System prompt** → вставьте содержимое
   [`ai-lab/skills/SKILL.md`](../ai-lab/skills/SKILL.md) (Денис пришлёт
   файл или дайте ссылку на этот репо).
3. **Connect to ai-lab connector** в настройках проекта.
4. Все боевые вопросы задавайте **внутри этого проекта**.

### Вариант B — первое сообщение в обычном чате

В новом чате первое сообщение:
> Действуй как AI Lab agent, строго следуй правилам:
> [Cmd+V — вставка SKILL.md]

Дальше задавайте вопросы — Claude помнит инструкции в этой сессии.

## Боевые сценарии

**Числовые расхождения по теме:**
```
Покажи все числовые расхождения по PRO-сегменту со светофором критичности,
цитатами из документов-источников и одной строкой бизнес-смысла под каждой
находкой.
```

**Сверка инициативы:**
```
Вот моя инициатива: <текст>. Проверь по корпусу — что подтверждается,
что противоречит, чего не хватает, есть ли похожие инициативы.
```

**Невыполненные обещания:**
```
Покажи незакрытые обещания по теме <тема>. Просроченные — выведи отдельно.
```

**Поиск:**
```
Что у нас написано про <тема>? Сделай выжимку из 2–3 документов с цитатами.
```

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| `unauthorized` | Токен правильный? `Bearer ` (с пробелом!) перед токеном? |
| `connection error` / `502` | Сервер мог рестартиться. Подождите 1 минуту, попробуйте `corpus_stats` ещё раз. Если не помогло — пишите Денису. |
| Ответы без таблиц/охвата | SKILL не подключён. Перечитайте «Применить skill». |
| Claude не вызывает `ai-lab` | В запросе явно скажите: «Используй ai-lab MCP», или «Вызови инструмент ai-lab corpus_stats». |

Любые серьёзные проблемы → Денис (din.kopylov@gmail.com).
