# AI Lab — подключение для коллег

**5 минут, без участия Дениса, работает 24/7.** Сервер живёт на Fly.io.
Нужно сделать два шага: подключить connector (доступ к данным) и
залить skill (правила, как Claude этими данными пользуется).

> ⚠️ **PoC-режим.** Сейчас сервер открыт без авторизации (Claude.ai

> URL не публикуется. Полноценная авторизация (OAuth) — после Demo Day.

## Что вам понадобится

1. **Claude.ai** (web или desktop), любая платная подписка (Pro / Team /
   Max — Custom Connectors и Skills доступны на платных тарифах).
2. **URL от Дениса:** `https://veyra.fly.dev/mcp` (токен не нужен).
3. **Файл skill:** `ai-lab-skill.zip` (Денис пришлёт; лежит в репо рядом
   с этим файлом).
4. **VPN с западным exit-нодом** (для api.anthropic.com). Если Claude.ai у
   вас уже открывается — VPN настроен.

## Шаг 1. Connector — доступ к данным (один раз)

1. В Claude.ai откройте **Settings → Connectors → Add custom connector**.
2. Заполните:

   | Поле | Значение |
   |---|---|
   | **Name** | `ai-lab` |
   | **Remote MCP server URL** | `https://veyra.fly.dev/mcp` |
   | **Advanced → OAuth Client ID / Secret** | **оставить пустыми** |

3. **Add connector**.
4. Готово — connector доступен во всех новых чатах.

### Проверка связи

В новом чате задайте:

```
Вызови инструмент ai-lab corpus_stats
```

Ожидаемый ответ — сводка по корпусу:

```
83 документа · 28 числовых расхождений · 2080 логических сигналов · 1055 открытых обещаний
```

Видите цифры — данные подключены. Можно тестировать уже сейчас.

---

## Шаг 2. Skill — качество ответов (рекомендуется)

Connector даёт Claude **инструменты**, а skill — **правила**, как ими
пользоваться (русский язык, бизнес-тон, формат таблиц, охват корпуса,
follow-up'ы). Без skill ответы будут «сырыми».

### Вариант A — загрузить skill (правильно, на постоянку)

1. **Settings → Capabilities** → убедитесь, что включён **Code execution**
   (без него skills недоступны).
2. Там же откройте раздел **Skills** → **Upload skill** (кнопка «+» /
   «Upload»).
3. Выберите файл **`ai-lab-skill.zip`** (от Дениса).
4. Skill `ai-lab` появится в списке — **включите тумблер**.
5. Готово: теперь Claude сам подхватывает правила, когда вопрос про
   корпус. Skill приватный — виден только в вашем аккаунте.

### Вариант B — Project (если skills недоступны на тарифе)

1. **Projects → Create project** → название `AI Lab`.
2. В **Custom instructions** вставьте содержимое `SKILL.md` (из zip или
   репо).
3. Подключите к проекту connector `ai-lab`.
4. Боевые вопросы задавайте **внутри этого проекта**.

## Боевые сценарии

**Числовые расхождения по теме:**
```
Покажи все числовые расхождения по PRO-сегменту со светофором критичности,
цитатами из документов-источников и одной строкой бизнес-смысла под каждой
находкой.
```

**Сверка инициативы:**
```
Вот моя инициатива: <текст>. Проверь по корпусу — что подтверждается,
что противоречит, чего не хватает, есть ли похожие инициативы.
```

**Невыполненные обещания:**
```
Покажи незакрытые обещания по теме <тема>. Просроченные — выведи отдельно.
```

**Поиск:**
```
Что у нас написано про <тема>? Сделай выжимку из 2–3 документов с цитатами.
```

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| `connection error` / `502` | Сервер мог рестартиться. Подождите 1 минуту, повторите `corpus_stats`. Не помогло — пишите Денису. |
| Claude не вызывает `ai-lab` | Скажите явно: «Используй ai-lab MCP» или «Вызови инструмент ai-lab corpus_stats». |
| Ответы без таблиц/охвата | Skill не подключён или выключен. Перечитайте «Шаг 2». |
| Upload skill недоступен | Включите **Code execution** в Capabilities; если нет раздела Skills — используйте Вариант B (Project). |

Любые серьёзные проблемы → Денис (din.kopylov@gmail.com).
