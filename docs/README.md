# Документация AI Lab — индекс

Набор документов проекта AI Lab (внутренний кодовик — «Хроника»).
Каждый документ самодостаточен; этот файл — карта набора и порядок чтения.

## Документы

| Документ | Назначение | Кому читать |
|---|---|---|
| [`ROADMAP.md`](ROADMAP.md) | Живой план проекта — этапы, задачи со статусом, решения. Отсюда ведётся работа. | Всем — текущий статус и план. |
| [`SYSTEM.md`](SYSTEM.md) | Полное описание системы с нуля: бизнес-проблема, что делает, архитектура, структура кода, слабые места, глоссарий. | Новичку — первым. |
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | Глубже про слои, модель данных, потоки, масштаб, безопасность. Источник правды по архитектуре. | Тем, кто разрабатывает или интегрирует. |
| [`TZ.md`](TZ.md) | Техническое задание (актуальная версия — v1.4). Возможности, фазы, гейт, принципы, открытые вопросы. Источник правды по требованиям. | Перед планированием работ. |
| [`LOAD-DOCS.md`](LOAD-DOCS.md) | Раннбук: как добавить новые документы в корпус (`index_docs.py --sync`). | Когда грузишь доки. |
| [`DEPLOY.md`](DEPLOY.md) | Бриф разработчику на деплой backend + ai-lab-mcp на Avito PaaS (топология, env, данные). | Когда выводим с личного компа. |
| [`SCALE-PLAN.md`](SCALE-PLAN.md) | План загрузки корпуса 100→300 документов: пошагово, чем мерить, риски. | Перед индексацией корпуса. |
| [`CASES-PLAN.md`](CASES-PLAN.md) | План вывода всех бизнес-кейсов на целевой путь (Claude через ai-lab-mcp): этапы, матрица готовности, что строить. | Для планирования разработки. |
| [`USE-CASES.md`](USE-CASES.md) | Каталог бизнес-кейсов в формате JTBD: что система должна уметь, статус и приоритет каждого. | Что AI Lab делает, по группам. |
| [`gate_report.md`](gate_report.md) | Результаты гейта детекторов Фазы 1: что проверено, метрики, границы достоверности. | Чтобы понять, что доказано, а что нет. |
| [`GAP-ANALYSIS-AVITO.md`](GAP-ANALYSIS-AVITO.md) | Сравнение AI Lab с AI-экосистемой Avito (MCP Hub, Skills Hub): что совпадает, какие гэпы, варианты решения. | Для приоритизации работ. |
| [`MCP-HUB-ONBOARDING.md`](MCP-HUB-ONBOARDING.md) | План и чек-лист регистрации `ai-lab-mcp` в MCP Hub Avito. | Когда подключаем ai-lab-mcp к Hub. |
| [`STATUS.md`](STATUS.md) | Снимок статуса сессии на дату. Устаревает — сверяйте дату. | Для быстрого «где мы сейчас». |

## Порядок чтения

1. **`SYSTEM.md`** — понять систему целиком.
2. **`ARCHITECTURE.md`** — устройство слоёв и данных.
3. **`TZ.md`** — требования, фазы, принципы.
4. **`SCALE-PLAN.md`** — как растить корпус.
5. **`gate_report.md`** + **`STATUS.md`** — что доказано и где проект сейчас.

## Приоритет при расхождениях

- По **требованиям** — `TZ.md` (в нём раздел 13 перекрывает разделы 1–12).
- По **архитектуре** — `ARCHITECTURE.md`.
- По **текущему состоянию** — свежий PR / git-лог; `STATUS.md` — снимок, может устареть.
