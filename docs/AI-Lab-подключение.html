AI Lab — подключение

Помощник, который находит в наших документах противоречия, незакрытые обещания и пробелы — с цитатой и ссылкой на источник. Настройка один раз, ~3 минуты.

С чего начать: нажми, чем ты пользуешься. Покажем только твои шаги.
Нужны: платная подписка Claude (Pro/Team/Max) и файл ai-lab-skill.zip (пришлёт Денис). Если Claude.ai у тебя открывается — VPN уже в порядке.
1

Подключить данные

  1. Claude.ai → Settings (⚙️) → Connectors → Add custom connector.
  2. В поле URL вставь ссылку:
https://veyra.fly.dev/mcp
Остальные поля (OAuth) оставь пустыми → Add. Токен/пароль не нужны.
2

Загрузить скилл

  1. Сохрани присланный файл ai-lab-skill.zip на компьютер.
  2. Claude.ai → Settings → Skills → Upload skill → выбери этот файл.
  3. В списке появится ai-lab — включи его.
Скилл — это «правила», по которым Claude пользуется данными (всегда даёт источник, не выдумывает). Без него тоже работает, но хуже.
3

Спросить

В новом чате проверь, что коннектор ai-lab включён (значок инструментов у поля ввода), и пиши обычными словами:

Что мы уже знаем про <тема>? Дай с источниками
Проверь инициативу: <текст>
Какие обещания по <теме> не закрыты?
Нет ли противоречий по <метрике> между документами?

Если не работает

Claude пишет «инструментов нет»В чате включи коннектор ai-lab — галочка в панели инструментов у поля ввода.
Claude.ai не открываетсяВключи западный VPN.
Нет «Add custom connector» или «Skills»Нужна платная подписка Claude.
Это для тех, у кого стоит приложение Codex и он в него вошёл. Ставить/качать ничего не надо — сервер уже в облаке, нужно вписать одну ссылку.
1

Подключить данные

  1. В Codex: значок ⚙️ → MCP settings → Open config.toml.
  2. Вставь в конец файла эти две строки и сохрани (Ctrl+S / ⌘S):
[mcp_servers.ai-lab]
url = "https://veyra.fly.dev/mcp"
Обычный текстовый файл — сломать этим нельзя. Сервер открытый: токен/пароль не нужны.
2

Добавить правила по желанию

Файл AGENTS.md (пришлёт Денис) сохрани в ту же папку, где открылся config.toml (то есть как ~/.codex/AGENTS.md).

Можно пропустить — заработает и без него, просто ответы будут «сырее».
3

Перезапустить и проверить

  1. Перезапусти Codex.
  2. В чате напиши:
вызови ai-lab corpus_stats

Ответит 128 документов и датой — всё работает. Дальше спрашивай обычными словами:

Проверь инициативу: <краткое описание>
Какие обещания по <теме> не закрыты?
Нет ли противоречий по <метрике> между документами?

Если не работает

Codex «не видит» ai-labПроверь, что две строки из шага 1 сохранились (⚙️ → MCP settings → Open config.toml), и перезапусти Codex.
Ошибка про url / «not supported»Обнови приложение Codex — подключение по ссылке появилось недавно.
corpus_stats молчитЕсли сам Codex отвечает в чате — сеть в порядке. Подожди минуту, повтори.
