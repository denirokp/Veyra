# AI Lab — подключение за 3 шага

**Что это.** Помощник внутри Claude.ai, который находит в наших
стратегических документах противоречия, незакрытые обещания и пробелы —
с цитатами и ссылкой на источник. Настройка один раз, ~5 минут.

**Перед началом:**
- Claude.ai с платной подпиской (Pro / Team / Max).
- Западный VPN включён. *(Если Claude.ai у вас открывается — VPN уже ок.)*

---

## Шаг 1 — подключить данные

1. Claude.ai → **Settings** (⚙️) → **Connectors** → **Add custom connector**.
2. В поле **URL** вставьте:

   ```
   https://veyra.fly.dev/mcp
   ```

3. Остальные поля (OAuth) оставьте **пустыми** → **Add**.

## Шаг 2 — загрузить скилл

1. Сохраните файл **`ai-lab-skill.zip`** (пришлёт Денис) на компьютер.
2. Claude.ai → **Settings** → **Skills** → **Upload skill** (или
   «Add skill») → выберите этот `ai-lab-skill.zip`.
3. Скилл `ai-lab` появится в списке — включён.

*(Скилл — это «правила», по которым Claude пользуется данными: всегда
даёт источник, не выдумывает, показывает охват. Без него тоже работает, но
хуже — поэтому загрузите.)*

## Шаг 3 — спросить

В новом чате (или в проекте) убедитесь, что коннектор **`ai-lab` включён**
(значок инструментов рядом с полем ввода), и напишите обычными словами:

- «Что мы уже знаем про <тема>?»
- «Проверь инициативу: <текст>»
- «Какие обещания по <теме> не закрыты?»
- «Нет ли противоречий по <метрике> между документами?»

---

## Если что-то не так

| Симптом | Что сделать |
|---|---|
| Claude пишет «инструментов нет» | В чате **включите коннектор `ai-lab`** (галочка в панели инструментов у поля ввода). |
| Claude.ai не открывается | Включите **западный VPN**. |
| Нет «Add custom connector» или «Skills» | Нужна **платная** подписка Claude. |

## Для владельца

- **Разошли коллегам:** этот файл (`CONNECT-SIMPLE.md`) + сам
  `ai-lab-skill.zip`. Для non-IT добавь 2–3 своих скриншота прямо в шаги —
  по картинкам заходит лучше любого текста.
- **Claude Team / Enterprise:** админ может включить коннектор **на всю
  организацию** (Admin → Connectors) → тогда у коллег отпадает **Шаг 1**
  (Шаг 2 — загрузку скилла — каждый всё равно делает сам).
- **Обновление скилла:** когда пришлёшь новую версию `ai-lab-skill.zip`,
  коллеге надо в **Settings → Skills** удалить старый `ai-lab` и загрузить
  новый (Claude не обновляет скилл сам).
