# Загрузка новых документов в корпус

Как добавить документы, чтобы AI Lab их видела. Делается на машине,
где запущен backend (локально или на PaaS-хосте).

## Мультитенантность (PoC) — изолированные корпуса

Каждый документ принадлежит `workspace` (команда/человек). Корпуса
изолированы: запрос к одному не видит документов другого. На PoC workspace
— флаг; в проде выводится из Keycloak-группы (см. `ARCHITECTURE.md §3.5`).

```bash
# два разных корпуса из разных папок
python scripts/index_docs.py --reset-all --workspace teamA --docs data/docs_A
python scripts/index_docs.py            --workspace teamB --docs data/docs_B
```
Проверка изоляции (backend должен быть запущен):
```bash
curl "http://localhost:8000/api/retrieve?query=...&workspace=teamA"   # только доки A
curl "http://localhost:8000/api/retrieve?query=...&workspace=teamB"   # только доки B
```
В MCP: `search_corpus(query, workspace="teamA")`. Без `--workspace` всё
идёт в `default` (старое поведение). `--reset-all` нужен один раз после
обновления схемы (добавилась колонка `workspace`).

## Шаги

1. Положи файлы в каталог документов (`.docx`, `.pdf`):
   ```bash
   cp ~/Downloads/мой-документ.docx backend/data/docs/
   ```
2. Запусти инкрементальную индексацию из корня репо (venv backend'а активен):
   ```bash
   cd ~/AI Lab
   source backend/.venv/bin/activate
   python scripts/index_docs.py --sync
   ```
   `--sync` НЕ сбрасывает базу. Для каждого файла:
   - новый → индексирует;
   - изменён (хэш не совпал) → переиндексирует;
   - не изменён → пропускает.
3. Проверь, что добавилось: через MCP «вызови corpus_stats» — число
   документов вырастет. Или повторный `--sync` покажет «не изменён».

> Без `--sync` (просто `python scripts/index_docs.py`) — это **первичная**
> индексация: она СБРАСЫВАЕТ базу и индексирует всё заново. Для добавления
> используй только `--sync`.

## Что нужно для индексации

- **LLM-доступ.** Индексация гоняет skills (извлечение сущностей, обещаний,
  логических сигналов, брифы) — это LLM-вызовы. На личном ключе упирается в
  rate-limit/кредиты; цель — Avito AI proxy (`LLM_BASE_URL` в `.env`).
- **Embedding-модель** — локальная, скачивается один раз (~500 МБ). После
  первого раза можно офлайн: `export HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1`.

## Если кредитов/доступа нет

Числовой детектор — детерминированный (без LLM) и отработает; но
LLM-skills (брифы, обещания, логика) на части документов упадут, и корпус
будет частично дырявым (как 28-док тест-прогон). Для чистого корпуса
сначала переключись на Avito AI proxy, потом индексируй.

## Bulk-загрузка большого корпуса

При заливке десятков-сотен документов отключи дорогой «бульон», чтобы не
тратить ~6 LLM-вызовов на документ:
```bash
ENABLE_BACKGROUND_SIGNALS=0 python scripts/index_docs.py --sync
```
Детекторы можно догнать позже. Стратегия батчей — `SCALE-PLAN.md`.
